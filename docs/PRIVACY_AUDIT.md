# 隐私审计报告（数据侧 + 模型侧）

> 本文件是课题"隐私审计流程"这一产出的落地文档。数据侧审计是**训练开始前**必做的一步（否则 τ 会被跨集重复样本抬飞，记忆率恒为 0）；模型侧审计就是本课题的主线指标 M(E) 与安全早停点 E\*(N, ε)。

## 1. 数据侧审计：跨切分重复

工具：`python -m tools.check_leak --size 64`（md5 完全重复 + 8×8 缩略图归一化后近似重复，`--thr 0.995`）

判据：训练集与测试集之间不应存在完全/近似重复样本。若存在，测试集就"泄漏"了训练集，用它校准 τ 会把阈值抬到真实记忆样本之上。

| 数据集 | 训练 | 测试 | 完全重复(测试侧) | 近似重复 | 缩略图相似 p99 | 结论 |
|---|---|---|---|---|---|---|
| pathmnist | 89996 | 7180 | 0 | 0 | 0.925 | 干净 |
| bloodmnist | 11959 | 3421 | **5** | **4** | 0.979 | 有跨集重复（MedMNIST 已知问题） |
| pneumoniamnist | 4708 | 624 | 0 | 0 | 0.977 | 干净 |

处理方式：**不删数据**（删了就不是官方切分了），而是在校准 τ 时把"与训练集相似度 ≥ `LEAK_COS`(0.99) 的参照图"剔除（`metric.calibrate_tau` 的 `n_leak_dropped` 字段逐点记录）。这样 τ 仍锚定 FPR = 0.5%，但不被重复样本污染。

> 若换到院内数据：同一步骤必须先跑，且要额外做**患者级**去重（同一患者的不同扫描不能跨 train/test），MedMNIST 不带患者 ID，所以这一步在公开数据上做不了 —— 写进限制。

## 2. 模型侧审计：记忆率 M 是什么、为什么可信

- **定义**：生成 n_gen 张样本，用编码器（DINOv2 ViT-S/14，384 维）提特征，在**训练集特征 bank** 上求最大余弦相似度；相似度 > τ 的样本比例即记忆率 M。
- **τ 的校准（关键）**：取测试集里 2000 张**从未参与训练**的图，对同一个训练 bank 求最大余弦相似度，取 `1 - FPR` 分位（FPR = 0.5%）。含义：**"一张从未见过的真图"有 0.5% 的概率超过 τ，所以 M 超过 0.5% 才是信号**。每个 N 单独校准（bank 越大，最大相似度的零分布越高，τ 必须跟着变）。
- **白化**：特征先做截断白化（`k = max(32, min(d, N/2))` 个主成分，收缩 1e-3）。不做白化的原始余弦会被"所有图都很像"的主导方向压平（28px 实测：非成员 p99.5 = 0.965，而真近复制品 p50 = 0.953，几乎不可分）。
- **编码器必须锁定**：DINOv2 与 ResNet50 给出的 τ 分别是 0.6721 与 0.8203，混用会让 M 直接归零。CSV 每行都记 `encoder` 列，工具在检测到混用时拒绝写入。
- **不做 EMA 会误判**：早期版本用最后一个 epoch 的权重采样，出现过 M 从 0.88 掉到 0.09 的"锯齿"，肉眼检查发现是采样塌陷（低对比度接近均值的紫块）。改用权重 EMA（decay 0.999）后曲线单调。**审计结论必须建立在 EMA 采样上**，否则会把采样不稳定误报成"记忆化非单调"。
- **不是重复计数**：同时报告去重感知的 M_uniq（相似度矩阵做贪心匹配）与固定阈值 M_050/M_060/M_070，确认结论不依赖单一阈值口径。

## 3. 审计流程（给医院/法务的落地版）

1. **数据准入**：`tools.check_leak` 跑跨切分重复 + 患者级去重（院内数据）；输出 `results/leak_report.json` 存档。
2. **训练中监控**：每 25–160 epoch 存 ckpt + 采样 512 张，算 M 与 FID，写 `results/metrics_long.csv`（含 encoder、τ、n_gend、n_leak_dropped 字段，审计链完整）。
3. **停训决策**：查控制律给出的 E\*(N, ε)，或用在线的 M 估计（策略 D）触发早停；ε 由机构隐私政策给定（本课题默认 ε = 1%）。
4. **交付审计包**：`results/metrics_long.csv` + `results/law_fit.json` + `results/law_bootstrap.json` + `results/stop_policy_summary.csv` + 本文件。
5. **复现**：`docs/PROTOCOL.md` 的记录 + `results/pilot28/`（小分辨率 pilot）与主结果分离归档。

## 4. 已知限制

- MedMNIST 是 28/64px 的降采样版本，不是原始 DICOM；记忆化强度与分辨率相关，绝对数值不能直接外推到临床分辨率。
- 生成模型只有 13M 参数（8 GB 显存的约束），容量小于文献里的 Stable Diffusion 级模型；本课题的结论是**控制律的形状与参数**，不是某个具体模型的绝对记忆率。
- 患者级去重、伦理审批、去标识化流程在公开数据上无法验证，只能写成院内数据接入的清单。
