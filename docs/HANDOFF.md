### 1.4 免测量的第二种交付形态（`results/seed_margin.csv`）

`E*_safe = E*_law · 10^(−2σ_log)`，σ_log = std(log10 onset)，判据是"该停点上所有 seed 都 ≤ ε"：

| N | seed 数 | σ_log | E*_law | E*_safe | 省轮 | M@law | M@safe | 质量代价 |
|---|---|---|---|---|---|---|---|---|

→ **帕累托阶梯**：闭环（省 67%、0 违规、质量代价小）> 开环+2σ（省 88–94%、0 违规、质量 1.5–2.5×）

### 1.6 其它可引用的稳健性结论

- **FPR 敏感性**：τ 校准目标 0.1%→1%（10 倍）只让 M 动 4 个百分点（N=250 末点 0.773→0.840）。
- **白化维数**：k=125/256/384 → M 只动 ±0.05（0.789→0.730），τ 本身从 0.748 掉到 0.128（不可跨配置比）。
- **换编码器**（DINOv2→ResNet50）：趋势 Spearman 0.84–0.99，但**幅度不稳健**（平台随 N 的斜率 −2.46 vs −1.13），
  所以 α 只能当"条件指数"报。
- **跨数据集**：函数族可迁移（bloodmnist 自由拟合 R²_log 0.984）、**参数不可迁移**（α 0.78 vs 1.90），
  即换医院必须自己标定，或直接用闭环。
- **类型学**：三个假说（少数派复刻 / 离群样本 / 类别偏斜）全被否 → 记忆化弥散在数据流形上，
  删样本不可靠，只能在时间轴上控（这正是闭环的动机）。
- **R 独立复算**：模型逐点差 0、四个 R² 逐位相同、独立重拟合差 3e-9、留一 0.4415 vs 0.4415。
- **与 NeurIPS 2025 的对照**（原文 §2 已逐字核对，2026-11-02）：等步数下 FID 与 N 无关（7 档极差 2.2%）
  → 复现"τ_gen 与 N 无关"；**onset 结构也复现**（`onset/N` = 11.07/10.63/10.40 步/张，斜率 0.95 ≈ 线性），
  但他们的判据是 Eq.(6) 像素最近/次近比 <1/3、常数 ≈300 步/张，我们约 10.5 步/张 → **可比斜率不可比常数**；
  用他们的判据复算我们的样本（`results/eq6.csv`）排序一致、幅度约严 2×。详见 `docs/COMPARISON.md` §2。

## 2. 哪几条结论"站得住"，哪几条必须打折

**站得住（可以直接写进摘要）**

1. 记忆化随训练时间单调上升，并在有限步数内饱和；**数据量越大，平台越低**（∝ N^−1.9）且**发作越晚**。
2. **固定时刻表给不了保证**：同一 N 下 seed 之间 onset 差 8–33 倍；纯开环在 43 个 run 上违规 11.6%。
3. **闭环能在 0 违规下省 69.6%**，而行业常用的 FID 平台早停省 20.2% 却违规 83.7% —— 主贡献。
4. 记忆化不是"少数危险样本"造成的（类型学三假说全否），所以只能用时间轴策略。
5. 测量协议可复现、对自由参数稳健、跨语言（Python/R）一致。

**必须打折（`docs/ALIGNMENT.md` 7 条偏差）**

1. 控制律 R² 0.710/0.683 < 预声明 0.9；留一 0.467 < 0.8。原因：可测范围只到 N≈1000–1500 + 子集方差 8 倍。
2. γ 与实测 onset 斜率**简并**，论文以实测斜率为主，γ 只作模型参数。
3. 分辨率只到 64px（28px 作 pilot 对照）；数据是 MedMNIST，不是原始 DICOM。
4. 隐私-质量不可兼得：28 行安全表 0 行四条件全过。
5. 编码器换了之后幅度不稳（α 是条件指数）。
6. 13M 参数的小 UNet，容量效应未扫。
7. 时间单位是 epoch，与文献的优化步差 N/64 因子。

## 6. 环境备忘（这台机器的坑，别再踩）

- **pip 不可用**（打印 `Looking in indexes:` 后 90% CPU 空转不退出）→ 依赖是 urllib 直下 wheel + zipfile 解包装的。
- **zenodo 不可达**、`hf-mirror.com` 会间歇性整体超时 → 64px 数据由 `build/get_hf64.py` 从 HF 的 224px 源本地转换。
- **`~/.cache/torch` 没权限** → `config.py` 把 `TORCH_HOME` 指到 `build/torch_home`，DINOv2/Inception 权重离线缓存。
- **PowerShell 判定退出码会骗人**：原生程序往 stderr 打警告（xFormers）会被当 `NativeCommandError`，
  于是"成功也 rc=1"。判成败看 `> out 2> err` 的 rc 与产物 mtime。
- **日志编码**：`*>>` 写 UTF-16LE 且中文被 GBK 化；用 `2>&1 | Out-File -Append -Encoding utf8`。
- **路径含单引号**（`C:\Users\yang'yu\...`）→ 别 `cd` 绝对路径，用 `workdir` 或相对路径。
- **heredoc 不可用**，`python -c` 里嵌双引号会被吞 → 多行 Python 一律落成 .py 文件。
- **`Set-Content -Encoding UTF8` 会给 .py 加 BOM** → 用 `build/strip_bom.py` 或写文件工具。
