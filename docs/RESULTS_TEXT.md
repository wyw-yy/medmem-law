## 4. 实验设置（一页）

**数据**：MedMNIST v2 的 pathmnist（89,996 张训练图，9 类）、bloodmnist（11,959）、pneumoniamnist（4,708）。
64×64 版本由公开的 224px 原始 JPEG 在本地重采样得到（切分与官方一致），以保证与文献同一量级的分辨率；
28px 版本仅作 pilot 对照（§5.6）。数据规模 `N ∈ {250, 500, 1000, 1500, 2000, 3000, 4000}`
用**嵌套子集**构造（同一 seed 下 `N=250` 是 `N=500` 的前缀，`np.random.default_rng(1000+seed)` 的排列前缀），
使不同规模之间的差异不来自"换了一批图"。

**模型**：小型 DDPM UNet（13.02M 参数，base channels 32，无 attention），线性 β 从 1e-4 到 0.02，
T=1000，AdamW lr 2e-4，bf16 混合精度，DDIM 50 步采样。**所有采样都用 EMA 权重（decay 0.999）**——
这不是可选项：不做 EMA 时同一 run 的相邻检查点会在 `M=0.88` 与 `M=0.09` 之间跳（采样塌陷），
会把"记忆化是否随训练上升"这个基本事实读错（`docs/NOTES.md` §1.5）。

**等步数预算**：文献的时间单位是优化步，所以每个 run 给**相同的梯度步数**（20,000 步，
大 N 的深度档 80,000 步），epoch 数按 `E = steps·64/N` 反比换算（N=250→5125 轮、N=4000→325 轮）。
好处是每个 run 的墙钟时间几乎相同（35–40 min），并且横轴 `E` 与 `N` 的乘积正好是步数。

**测量**：每 25 个 epoch（或按 32 个等间隔点）存一次权重、采 512 张图，按以下三步算记忆率
`M` = 与训练集最近邻相似度超过阈值 `τ` 的生成样本占比：
①编码器 DINOv2-ViT-S/14 提特征（384 维，224 输入）；②在训练集特征上做**截断白化**
（保留 `k = max(32, min(d, N/2))` 个主成分，收缩系数 1e-3）；
③`τ` 用**非成员图**（官方 test split，2,000 张）对训练集的最大余弦相似度的 99.5 百分位标定，
即把假阳性率固定为 0.5%。校准前先用 `tools/check_leak.py` 剔除跨 split 的近重复（bloodmnist 有 5 张完全重复 + 4 张近似）。
生成质量用 FID（Inception-v3，64×64 上采样到 299）。

**拟合**：六个候选律（L1 拉伸指数 / L2 Hill / L3 双时间尺度 erf / L4 幂律幅度衰减 / L5 仅幅度衰减 / L6 指数幅度衰减），
参数用多起点 `least_squares` 在 `log10(M+1e-4)` 空间拟合。**低于检出限的点按删失数据处理**：
`M=0` 的观测不当作"恰好 1e-4"，而用一个单侧 softplus 惩罚（`CENSOR_K=4`），
因为 512 张样本里 0 命中只说明 `M < 3/512`。选型判据**预先声明**：AICc 最小 → 留一 N 池化 R² 最大 → 参数可解释。
验收线：样本内 `R²_log ≥ 0.9` 且留一 N 池化 `R² ≥ 0.8`。

**计算**：全部 34 个 run 在单张 RTX 5070 Laptop（8 GB，功耗墙把时钟压到 ~200 MHz）上完成，
共 1,266 个测量点、约 26 GPU·小时，峰值显存 2.19 GB。R 4.6.1 独立复算拟合与 bootstrap（`R/verify_in_R.R`，base R 无外部包）。

## 5. 结果

### 5.1 记忆化在有限步数内饱和，且数据越多平台越低

`figs/fig1_triptych.png` 面板 (a)：7 档 `N` 的 `M(E)`。所有档位都表现为"**一段静默期 → 快速上升 → 饱和**"，
但两件事随 `N` 变化方向相反：

- **发作时间变晚**：到 1% 记忆率所需步数的实测斜率为 `+0.64`（pathmnist；`ε` 从 1% 到 5% 时为 0.68–1.52），
  即 `onset ∝ N^0.6~1.5`；
- **平台变低**：seed 均值平台为 0.863(250) / 0.469(500) / 0.092(1000) / 0.021(1500) / ≤0.014(2000–4000)，
  面板 (b) 的幂律拟合斜率 **−1.67**（只用地板以上的点），与律的幅度指数 `α = 1.896 [1.810, 1.980]` 同向。

也就是说，**在医学影像这个量级上，"多买数据"对隐私的收益主要来自把平台压下去，而不是把发作时间往后推**。
这条结论对采购决策比"onset 幂律"更有用，而且它是我们数据里最强的一条（7 档、5–9 seed、两种编码器、两个数据集一致）。

### 5.2 控制律：方向可信，拟合优度未达标

选出的模型是**幅度衰减的拉伸指数**（L4）：

```
M(N, E) = A0 · (N/250)^(-α) · [ 1 - exp( -(E / (E50_0 · (N/250)^γ))^β ) ]
A0 = 0.507 [0.404, 0.612]，α = 1.896 [1.810, 1.980]，β = 2.316 [1.805, 4.527]，
E50_0 = 2108 [1525, 2489]，γ = −0.831 [−0.899, −0.734]（bootstrap 200 次，95% CI，`results/law_bootstrap.json`）
```

样本内 `R²_lin = 0.710`、`R²_log = 0.682`；**留一 N 池化 R² = 0.464**（逐 run 口径 0.681）。
预声明的 0.9 / 0.8 **没有达到**。我们排查了三类原因，并给出证据说明这不是"模型选错"：

1. **可测范围太窄**：`N ≥ 1500` 的档位在 2 万–9 万步内 `M_max` 多数 < 5%（不到 25 张图），
   相对 512 张样本的量化步长 1/512 = 0.2%，这些点只能进删失项。只用"平台 ≥ 2%"的档（N ≤ 1000）拟合，
   可测区间 R² 是 0.443/0.557 —— **误差集中在有信号的区域**，不是被噪声坑了。
2. **七种律形式都过不了**：包括让形状参数随 N 变的 6 参数版本（`build/probe_beta_n.py`），
   样本内最高 0.855、留一最高 0.496，且参数撞边界（`β0` 撞上界 8、`δ=−1.10` 不可辨识）→ 按"参数可解释"判据否决。
3. **误差主要在幅度项而不是时间项**：只用 20 个可比 run 做分解，原样 SSE 74.2 → 只调时间轴 41.6（消 44.0%）
   → 只调幅度 15.9（消 **78.6%**）；只用 pathmnist 时 55.7 → 28.6 → 13.5。也就是说
   **"什么时候开始背"我们拟合得还行，"背多少"随 N 的非平滑衰减才是短板**（逐档 bias 0.86/0.42/1.72/2.27/0.42）。

诚实结论：本工作给出的是**方向正确、参数可解释、但外推到未见 N 不可靠**的控制律；
它的价值在"解释与预测趋势"，不在"给任意 (N,E) 一个精确的 M"。真正能落到部署上的是 §5.4 的闭环。

### 5.3 同一 N 下 seed 之间的差异比 N 的影响还大

固定 `N=1000`、换 5 个 seed（不同训练子集），到 1% 记忆率所需步数是 **2,344 / 4,688 / 12,891 / 15,234 / 18,750**，
极差 **8 倍**；`N=250` 的 9 个 seed 极差达 33 倍（`docs/NOTES.md` §8、§13）。
换 seed 等于换数据集，这不是初始化噪声，而是真实异质性。

**这条结论直接决定交付形态**：任何"固定时刻表"（包括用控制律算出的 `E*`）都只能描述**期望**，
无法保证单个 run 不越线 —— 实测开环律在 34 个 run 上违规 **11.8%**，而 FID 平台早停违规 **79.4%**。

### 5.4 闭环早停：省 66.6%、违规 0

`figs/fig1_triptych.png` 面板 (c) 与 `results/stop_policy_summary.csv`（34 个 run，`ε=0.01`）：

| 策略 | 平均轮次 | 省轮 | 停点 M | 违规率 |
|---|---|---|---|---|
| A 跑满（常规做法） | 2728.7 | 0% | 0.300 | 79.4% |
| B FID 平台早停 | 2145.8 | 23.9% | 0.291 | 79.4% |
| C 开环律 `E*(N,ε)` | 682.1 | 64.8% | 0.0059 | 11.8% |
| **D 闭环（每检查点实测定阈）** | **683.5** | **66.6%** | **0.0028** | **0%** |
| **D′ 闭环 + 律预测（加速触发）** | 683.5 | 66.6% | 0.0028 | 0% |

关键对比是 **D vs B**：同样"省轮次"的动机，基于 FID 的平台判据在 34 个 run 里有 27 个已经越线
（因为 FID 在整个记忆化上升期都还在缓慢改善，见 `figs/fig_quality.png`），
而按 `M` 刹车的闭环一次都没越线。**这就是"用生成质量做早停信号是错的、必须用隐私量本身"的直接证据。**

交付语义也定了：闭环在检测到越界的检查点**不回退训练**，而是**交付上一个仍然合规的检查点**
（`controller.py: stop_D` 的 `hit_idx-1`）——否则"违规率"会变成测量延迟的度量，而不是策略的质量。

### 5.5 免测量的第二种形态：开环 + 2σ seed 余量

如果医院不想在训练时挂测量管线，可以用 `E*_safe = E*_law · 10^(−2σ_log)`（`results/seed_margin.csv`）：
在 N=250/500/1000 上省 **88–94%** 轮次、**所有 seed 都合规**，代价是 FID 为跑满的 **1.55–2.54 倍**
（省掉的正是质量还在快速改善的区间）。
一个有意思的副产物：`σ_log` 随 N 增大（250/500 ≈ 0.05，N=1000 达 0.34），即"数据越多平台越低，但发作时刻更飘"，
固定时刻表的可信区间反而变宽 —— 又一个支持闭环的理由。

### 5.6 稳健性

- **阈值口径**：`τ` 校准目标从 FPR 0.1% 换到 1%（10 倍），N=250 末点 `M` 只从 0.773 变到 0.840（4 个百分点，`results/fpr_sensitivity.csv`）。
- **白化维数**：`k=125/256/384` 时 M 只变 ±0.05（0.789→0.730），但 `τ` 从 0.748 掉到 0.128 —— 所以 `τ` 不可跨配置比较，`M` 可以。
- **编码器**：换 ResNet50 重算，趋势 Spearman 0.84–0.99，但平台随 N 的斜率从 −2.46 变 −1.13 —— **α 只能当条件指数报**。
- **跨数据集**：bloodmnist 自由拟合 `R²_log=0.984`，但用 pathmnist 的参数迁移只到 0.534，α 从 1.90 变 0.78 —— **函数族可迁移、参数不可迁移**。
- **分辨率**：28px pilot 与 64px 主线结论同向（28px 的 M 偏高、τ 偏低 0.015–0.096），绝对 M/FID 不可跨分辨率比。
  224px 另跑了一档（pneumoniamnist N=1000、30,000 步、8 点 × 128 张）：FID 从 472 降到 110–117、像素 std 12→31，
  但 `M` 全程 0、`sim_max` 0.24–0.27 始终低于 τ=0.352 —— **判 inconclusive**（保真度不足以区分"不记忆"与"还没学会复刻"，
  且 batch 16 与主网格 64 不同），故不据此声称分辨率无关，只写进 limitation。
- **独立复算**：R 与 Python 的逐点预测差 0、四个 R² 逐位相同、独立重拟合的参数差 3e-9。

### 5.7 我们没能做到的（写进 limitation 的三句实话）

1. `R²` 没到 0.9 —— 因为可测范围只到 `N ≈ 1000–1500`，以及平台随 N 的衰减不是平滑幂律。
2. 隐私与质量在给定预算内不能同时满足 —— 28 行安全表里四条件全过 **0 行**；
   想在 `ε=1%` 下保质量，唯一的路是加数据，不是挪停点。
3. 结论建立在 MedMNIST（64×64、非 DICOM）与 13M 参数的小 UNet 上；更大分辨率/更大容量下的定量系数需要重新标定
   （接口已留好，见 `REPRODUCE.md` 与 `docs/HANDOFF.md` §4）。
