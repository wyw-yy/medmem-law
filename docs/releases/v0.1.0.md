## 这个 tag 是什么

论文《医学影像生成模型的记忆化控制律：数据规模、训练轮次与记忆率》的**全部实测产物与代码**。
正文里出现的每一个数字，都能通过 `docs/SUPPLEMENT.md` 的映射表追到本 tag 里的某个 CSV 行与某条命令。

- **38 个训练 run**，**1265 个测量点**（每个点 = 一个检查点的 512 张合成样本评分）
- 7 档数据规模 N ∈ {250, 500, 1000, 1500, 2000, 3000, 4000} × 5–9 个随机子集（seed）
- 3 个公开数据集（PathMNIST 主实验，BloodMNIST / PneumoniaMNIST 跨数据集）
- 64px（主线）/ 28px（pilot）/ 224px（对照，结论为不确定）

## 三条主结论

| # | 结论 | 证据强度 |
|---|---|---|
| 1 | 记忆化平台随数据量急剧下降：**平台 ∝ N^−1.90**（95% CI [1.81, 1.98]）；N ≥ 2000 时跑 8 万步仍 < 2%（低于检出限） | 强 |
| 2 | 控制律只能给"期望时刻表"：**R² = 0.710（线性）/ 0.682（对数）**，**未达预声明的 0.9**；留一池化 R² **0.464**，也低于 0.8 | 诚实未达标 |
| 3 | **闭环（在线测记忆率再停）是唯一能保证的形态**：34 个 run 上省 **66.6%** 轮次、违规 **0/34**；FID 早停省 27.7% 但违规 **79.4%** | 强 |

## 刻意保留的负结果

- 四条件严格安全表：**0/28 行全过**（放宽任一条就能"有结果"，本仓库不放宽）
- 224px 分辨率对照：**不确定**（30k 步仍 M=0 且像素 std 30.8 —— 无法区分"不记忆"与"还没学会生成"）
- 开环律跨 seed 不保证：onset 时间跨 seed 差 20–63 倍

## 怎么验证（不需要 GPU、不需要数据集）

```bash
git clone https://github.com/wyw-yy/medmem-law.git && cd medmem-law
pip install numpy pandas scipy
PYTHONPATH=. python -m tools.ci_check
```

会依次检查：SHA256 清单一致、测量表 7 条规则、22 条论文声明（PASS 数不得下降、已知 3 条未达标项不得变成 PASS）、**用同一张表重跑律拟合**（参数最大相对偏差 < 1%）、以及 base R 独立复算（24 条对照，0 条冲突）。

CI 每次 push 自动跑同一套（`.github/workflows/ci.yml`），最近一次：两个 job 全绿，R 复算在 Linux + 不同 R 版本上依然 0 冲突。
