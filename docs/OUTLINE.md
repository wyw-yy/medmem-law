## 一句话主张（v2）

合成医学影像的**记忆率 M** 可以被一个按假阳率校准过的近邻度量稳定测出来；它随训练推进而**从 0 起跳并饱和**，
饱和高度随数据规模按 **∝ N^-2.0** 塌下去（`α=1.97`）。但**同一 (N,E) 处不同训练子集（seed）的发作时刻相差最多 8 倍** ——
这个方差比"数据规模从 250 涨到 1500"的系统位移还大。所以：

> **律只能给期望停点，保证必须来自边训边测的闭环。**

这是本文两个贡献的关系，也是最有临床意义的一句：按 FID 平台早停（工业界默认做法）在 28 个 run 上**违规率 75%**；
按闭环在线测 M 再停，**违规率 0%，同时省掉 59% 的训练轮次**。

## 必须诚实写出来的六件事（审稿人一定会问）

1. **R² 没到 0.9，而且我们查清了为什么**。预声明是 R²_log ≥ 0.9 且留一池化 ≥ 0.8；实测 0.682 / 0.464。
   已排除"模型选错"：七种律形式（含形状随 N 变的 6 参数版）全部落在 R² 0.70–0.83；只用可测点重拟合到 0.745；
   换阈值重拟合同向。真正的原因是**子集方差**（见 2）与**可测范围太窄**（见 5）—— 这是数据的性质，不是拟合的失误。
2. **子集方差 8 倍**：N=1000 的 5 个 seed，到 1% 记忆率分别需要 2344 / 4688 / 12891 / 15234 / 18750 步。
   换 seed = 换训练子集 = 换数据集，所以这不是"初始化噪声"而是真实的异质性。
   **后果**：任何固定时刻表都无法保证单个 run 不越线；"最差 seed 口径"是唯一诚实的口径，
   要么给 2σ 余量（质量变差），要么上闭环（省得少但 0 违规）。
3. **γ 的符号、坐标与简并**。epoch 坐标 γ=−0.831 ⟺ 名义 t50 ∝ N^0.169；但**实测 onset 斜率是 0.64**（pathmnist）、
   0.66（bloodmnist）、1.20（pneumoniamnist）。两者不一致来自 L4 中"幅度随 N 衰减"与"时间尺度随 N 平移"的**简并**，
   所以论文以**实测 onset 斜率**为主结论，γ 只作为模型参数报告。
4. **度量有地板**：τ 按 FPR=0.5% 校准，一个都没记住时也有约 0.5% 样本越线（512 张里 2–3 张）。
   ε ≤ 2×FPR 的档位没有信息量，交付档位从 ε=2% 起。
5. **可测范围只到 N≈1000–1500**：N≥1500 的档在 2 万–9 万步内 M_max 多数 <5%（不到 25 张图），只能当删失数据。
   留一 N 外推到这些档必然不可靠 —— 这条既解释了 R² 的天花板，也界定了结论的适用范围。
6. **早停有质量代价，且没有"全都过"的配置**：安全表 28 行里四条件全过 **0 行**；小 N 档早停后 FID 涨 2–6 倍
   （N=250：123 → 341）。想在给定隐私预算内保质量，唯一的路是**加数据**，不是挪停点。

## 章节骨架

### Abstract（最后写，150 词）
问题（合成影像可能复刻训练病例，但没人知道"什么时候"）→ 缺口（缺校准过的定量规律）→ 做法
（等步数网格 7 档 N × 最多 5 seed，973 个测量点，FPR 校准的近邻记忆率）→ 结果
（平台 ∝ N^-2.0；onset 步数 ∝ N^0.6–1.2；闭环早停省 59% 且 0 违规，FID 平台早停违规 75%）→
限制（可测范围 N≲1500；子集方差 8 倍 → 律只能给期望）。

### 1. Introduction
- 钩子：医院用扩散模型"补充"影像，法务要回答"这张合成图会不会就是某位病人的片子"。
- 现有做法：按 FID 或固定 epoch 停 → 与隐私无关。数据：FID 平台早停的违规率 **75%**。
- 本文：把 M 变成可测、可拟合、可反解的量；并证明"为什么必须闭环"（子集方差 8 倍）。

### 2. Related work
- 机制：Bonnaire et al. 2025（NeurIPS Oral；τ_gen 与 N 无关、τ_mem ∝ N 的双时间尺度）。
- 攻击与度量：Carlini 2023、Somepalli 2023、Deo et al. ISBI 2026（MRI 上校准过的 MI）、
  SSCD（自监督描述子）、Kynkäänniemi 2019（密度/覆盖）。
- 数据侧干预：去重/选样（本组 datadiet-ehr 经验）。

### 3. Method
- 3.1 **测量**：M = 与训练集近邻余弦相似度 > τ 的生成样本比例；τ 由非成员参照集（test split）
  的最大相似度 99.5 百分位校准（FPR=0.5%）；DINOv2-S + 白化截断 `k=max(32,min(d,N/2))`；
  另报去重感知 `M_uniq` 与固定阈值 `M_050…M_095`（回答"是不是靠调阈值"）。
- 3.2 **实验设计**：**等优化步预算**（20000 步/run，epoch 按 N 反比缩放），7 档 N
  `[250,500,1000,1500,2000,3000,4000]`，N≤1000 最多 5 个 seed；大 N 深档给 3.75–9 万步；
  每 run 25–59 个测量点；**EMA 权重采样**（否则 M(E) 出假锯齿，`docs/NOTES.md` §1.5）。
- 3.3 **律拟合**：6 个预声明候选 + 2 个修订候选（L4 幅度衰减 / L5 幅度衰减·γ=0）；
  删失数据单侧惩罚（M=0 的点只进罚项不进 R²）；多起点按参数名生成；留一 N 用**池化** R²。
- 3.4 **早停策略**：A 固定跑满（基线）、B FID 平台、C 开环律 E*(N,ε)、D 闭环在线测 M；
  判据 = M_stop ≤ ε（**最差 seed**）、省 epoch、FID 相对代价 ≤ 1.5、ε > 2×FPR。

### 4. Experiments
- 4.1 主结果：M(E) 七条曲线（`fig_M_vs_E.png`）+ 平台高度随 N 的衰减（`fig_amplitude.png`，α≈2.0）。
- 4.2 律的选择与稳健性：候选表（R²_log/R²_lin/可测区间 R²/AICc/留一池化）+ 阈值扫描 + 白化维不变性 + FPR 敏感性。
- 4.3 跨数据集：`fig_cross_dataset.png` + `results/transfer.csv`
  （**函数族可迁移、参数不可迁移**：bloodmnist 自由拟合 R²_log 0.984，但 α 0.78 vs pathmnist 1.97）。
- 4.4 **子集方差**（新增小节，`docs/NOTES.md` §8）：同一 N 下 5 个 seed 的 onset 步数表 → 8 倍极差 → 为什么必须闭环。
- 4.5 停训策略对比：`fig_stop_policies.png` + `RESULTS.md` §5（最差 seed 口径）。
- 4.6 安全早停交付表：`results/safe_early_stop.csv`（每行标 ε 是否高于假阳性地板 + 质量是否可接受）。

### 5. Discussion
- 临床落法：三阶段 —— ①小规模标定（每档 N 跑 1 条曲线）②按律规划期望停点 ③上线后闭环守卫。
- 为什么"加数据"比"调停点"更有效：平台高度 ∝ N^-2.0，而停点只挪时间轴；大 N 档最终连 ε=5% 都到不了。
- 限制：MedMNIST 而非 DICOM；13M 参数；64px；只测图像近邻（不是成员推断攻击）。

### 6. Limitations & Ethics
- 复刻判定是"度量"而非"证明"：相似 ≠ 同一位病人，需结合院内 DICOM 复核。
- 闭环控制器需要每个检查点采样 512 张（64px 约 18 s），这个成本必须写清。
- 院内数据（伦理审批后）留作 future work：`docs/PRIVACY_AUDIT.md` 给了五步审计流程。
