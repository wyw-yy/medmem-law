## 0 对方主张（引用时的口径）

Bonnaire, Urfin, Biroli, Mézard, *Why Diffusion Models Don't Memorize: The Role of Implicit
Dynamical Regularization in Training*, **NeurIPS 2025 Oral + Best Paper**, arXiv:2505.17638。

三个可检验的主张：

| 记号 | 主张 | 含义 | 原文出处（已核对） |
|---|---|---|---|
| τ_gen | 与数据量 n **无关** | 开始"生成得像"的时刻只由优化动力学决定 | §2：FID 降到最小值的时间 τ_gen ≈ 100K 步，"does not depend on n" |
| τ_mem | 随 n **线性增长** | 开始"背下来"的时刻被数据量线性推迟 | §2：`f_mem(τ)/f_mem(τ_max)` 对 `τ/n` 塌缩，在 `τ/n ≈ 300` 处上升 |
| n 阈值 | 超过阈值后无限训练也不背 | 安全窗口随 n 变宽，最终消失 | §2：`f_mem(τ_max)` 的终值随 n 变（原文只给定性） |

他们的时间单位是**优化步（gradient steps）**，batch = `min(n, 512)`，数据是 CelebA 灰度 32×32，
模型 U-Net 3 层、base width 32（约 4M 参数）。这三点决定了我们所有换算。

## 1 复现：质量起点确实与 N 无关（强支持）

在**相同步数预算**（≈625 步 = 第一个检查点）下取 FID：

| N | 首个检查点 | 首个 FID | 末点 FID |
|---|---|---|---|
| 250 | e160 | 341.5 | 131.0 |
| 500 | e80 | 345.0 | 168.2 |
| 1000 | e40 | 344.3 | 210.6 |
| 1500 | e25 | 344.4 | 209.5 |
| 2000 | e20 | 337.4 | 226.2 |
| 3000 | e15 | 339.3 | 150.4 |
| 4000 | e10 | 340.3 | 137.7 |

**7 档 N 的首个 FID 极差 7.6（相对 341.7 的 2.2%）** —— 在等步数下，数据量从 250 变到 4000
完全不影响"开始生成得像"的时刻。这是对 τ_gen 与 n 无关的直接复现。

而末点 FID 随 N 单调变差（131 → 226），因为等步数预算下大 N 的"每张图被看过的次数"少
（`steps × batch / N` 从 32 降到 5）。这条也在他们的框架内：质量由步数决定，不由 epoch 决定。

## 2 记忆化判据：先对齐"怎么算记住"，再谈斜率

### 2.1 原文的判据（Eq.6，逐字核对）

一个生成样本 `x` 算"记住"，当且仅当

```
E[ ‖x − a_μ1‖₂ / ‖x − a_μ2‖₂ ] < k ,      k = 1/3
```

其中 `a_μ1`、`a_μ2` 是 `x` 在**训练集里、像素 L2 意义下**的最近与次近样本。
原文注：`k` 改成 `1/2` 或 `1/4` 不影响关于 scaling 的结论。

这是一个**无参数的相对判据**：不看"有多像"，只看"是否显著比第二像的更像我"。
它天然对模糊/均值化的样本免疫（模糊图的 d1 与 d2 差不多，比值接近 1）。

我们的主指标 `M` 是另一种东西：**白化 DINOv2 特征余弦 ≥ τ**，τ 按 FPR=0.5% 逐 N 校准。
两者不能混比，所以我们按他们的定义独立实现了一遍（`build/eq6.py`，像素 L2、k=1/3、无参数）。

### 2.2 用他们的判据复算我们的样本（`results/eq6.csv`）

| run | N | 我们的 M（特征余弦，FPR=0.5%） | 原文 f_mem（像素比 < 1/3） |
|---|---|---|---|
| `bloodmnist_n250_s1@e5125` | 250 | **0.971** | **0.672** |
| `pathmnist_n250_s1@e5125` | 250 | **0.805** | **0.412** |
| `pathmnist_n1000_s1@e2400` | 1000 | 0.066 | 0.014 |
| `pneumoniamnist_n64_s31@e2000` | 64 | 0.000 | 0.008 |
| `pathmnist_n2000_s2@e540` | 2000 | **0.041** | **0.000** |
| `pathmnist_n2000_s2@e2900` | 2000 | 0.004 | **0.000** |

→ **排序在可测区间内一致**（0.971 > 0.805 ≫ 0.066 > 0.000），四个档的相对关系都保住了；
→ **绝对幅度上像素比判据约严 2 倍**（0.41 vs 0.80）。也就是说，我们报的 M 里约一半是
"很像但不是像素级复刻"的样本——这正好是"特征空间近邻"与"像素级拷贝"的差别；
→ **大 N 档是关键差别**：`pathmnist_n2000_s2@e540` 在我们口径下 `M=0.041`（21/512 张越线），
但像素比中位数 0.98（最近与次近几乎等距）、`f_mem=0.000` —— 那 21 张**不是复刻，是"像"**。
所以**大 N 档的平台值只能当真实复刻率的上界**，这也是我们把 N≥1500 当删失数据的另一个理由。

### 2.3 onset 的 N 依赖：结构一致，常数差 30 倍

`results/grid_summary.csv` 的 `steps_1pct`（到 1% 记忆率所需步数）按 N 平均：

| N | seed 数 | onset 步数 | **onset/N** | 是否可测 |
|---|---|---|---|---|
| 250 | 9 | 2,768 | **11.07** | ✅ |
| 500 | 8 | 5,313 | **10.63** | ✅ |
| 1000 | 9 | 10,400 | **10.40** | ✅ |
| 1500 | 2 | 12,891 | 8.59 | ⚠ 弱信号（平台 2.1%） |
| 2000 | 2 | 8,438 | 4.22 | ❌ 量化噪声 |
| 3000 | 2 | 19,453 | 6.48 | ❌ 量化噪声 |
| 4000 | 2 | 16,875 | 4.22 | ❌ 量化噪声 |

**在记忆可测的 N ≤ 1000 区间，`onset/N` 稳定在 10.4–11.1，log-log 斜率 0.95 ≈ 线性。**
N ≥ 1500 的 onset 是被"1–3 张图偶然越线"提前出来的（平台只有 1–2%），放进回归会把斜率压到
0.64——**此前那个 0.64 就是这么来的，已作废**（`docs/PROTOCOL.md` §24 R16 记录了更正）。

结论可以写成一句可检验的话：

> 我们**复现了 τ_mem ∝ n 的结构**（可测区间斜率 0.95，95% 意义上与 1 不可区分），
> 但常数差约 30 倍：我们 ≈ 10.5 步/张，他们 ≈ 300 步/张。
> 这个差距的合理来源是判据（特征余弦 vs 像素比，§2.2 已显示后者严 2 倍）、
> 数据（64px 9 类 MedMNIST vs 32px CelebA 人脸）、以及模型容量与 batch 规则。
> **不比绝对值，只比结构。**

### 2.4 为什么律的 E50 给 +0.15 而 onset 给 +0.95（不矛盾）

| 口径 | 量 | 指数 | 怎么读 |
|---|---|---|---|
| 律的 E50（升到平台一半） | `E50 = E50₀·(N/250)^γ` | **γ = −0.831** ⟹ 步数坐标 **+0.169** | 模型参数，描述"半高"的时间尺度 |
| 固定绝对阈值 ε 的实测 onset | 首次 M ≥ ε 的步数 | **+0.95**（可测区间） | 部署意义上"什么时候开始不安全" |

两者的差正是**幅度塌缩**的贡献：平台高度本身随 N 掉 `A(N) ∝ N^−1.9`，
所以在固定 ε 下"越线"要比"到半高"多走一段，固定的 ε 把幅度信息折算成了时间。
这也是为什么**报告以实测 onset 为主、γ 只作模型参数**（`docs/PROTOCOL.md` §14 R7）。

在 7 档数据上，这两种描述在实践上可区分：N ≥ 2000 在 8.5–9 万步内 `M_max ≤ 4%` 且**不再随步数上涨**
（`n2000_s1` 在 e540 达 0.0059 后到 e2900 掉回 0.0039；`n4000_s1` 全程 ≤ 1.6%）。
按"时间推迟到无穷"读，这意味着"还没等到"；按"幅度衰减到 0"读，这意味着"到不了"。
我们的判据（`results/law_fit.json` 的 `censored_compliance` 0.80）偏后者，但**两者在现有步数内不可完全分辨**，
这一点写进 limitation。

## 3 我们这边文献里没有的两条

| 结论 | 数字 | 证据 |
|---|---|---|
| 平台高度有独立的 N 律 | `A(N) ∝ N^(−1.97 [1.88, 2.05])` | `results/law_fit.json`、`figs/fig_amplitude.png` |
| 同一 N 下不同训练子集的发作时刻抖 8–60 倍 | N=1000 的 onset 步数 2344/4688/12891/15234/18750 | `docs/NOTES.md` §8、`results/grid_summary.csv` |

第二条是文献不会报告的（他们通常单 seed 或报均值），但它直接决定工程结论：
**固定时刻表只能给期望，给不了保证**；要保证就得在线测（我们的闭环 D，34 run 零违规）。

## 4 我们的结论与他们的结论如何并用

| 问题 | 文献给的答案 | 我们给的答案 | 工程含义 |
|---|---|---|---|
| 什么时候开始背？ | τ_mem，随 n 线性推迟（≈300 步/张） | 同样是线性推迟（≈10.5 步/张），常数与判据/数据强相关 | 时间表能估，但**不能当保证**（seed 方差 8–60×） |
| 数据多了会怎样？ | 超阈值后永不背 | 平台高度 A(N) ∝ N^−1.97 衰减 | 加数据是真防线，但不免费（FID 131→226） |
| 安全早停怎么定？ | 训到 τ_mem 之前 | 闭环在线测 M，停在上一个合规检查点 | 34 run 零违规，省 66.6% 轮次 |

## 5 引用时的写法（避免被审稿人抓）

1. **可以写**"在等步数设定下，我们复现了质量起点与 N 无关（首个 FID 极差 2.2%），
   并复现了记忆化起点 ∝ N 的线性结构（可测区间斜率 0.95）"。
2. **必须同时写**判据差异：他们的 f_mem 是像素 L2 最近/次近比 < 1/3，我们的 M 是白化特征余弦
   ≥ τ(FPR=0.5%)；① 排序一致（§2.2），② 幅度我们更宽（约 2 倍）。
3. **不要比常数**：≈10.5 步/张 vs ≈300 步/张，差异来自判据 + 数据 + 容量 + batch 规则，
   我们在 64px MedMNIST 上，他们在 32px CelebA 上。
4. 时间单位必须写清：我们的 E 是 epoch，`steps = E · N / batch`（batch = 64）。
5. `A(N)` 与 `E50(N)` 的简并是这套拟合的已知弱点（`docs/NOTES.md` §10：只放开幅度
   一个自由度就能消掉 79% 的残差），引用 α 与 γ 时要同时给 CI。
