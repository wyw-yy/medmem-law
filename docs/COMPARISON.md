# 与 Bonnaire et al. (NeurIPS 2025 Oral) 的定量对照

> 目的：PPT 03② 写的"双时间尺度分离（NeurIPS 2025 Oral）"是我们的出发点。这一页回答两个问题：
> **① 我们复现了他们的哪一条？② 我们在哪一条上有出入，出入是方法差异还是真结论差异？**
>
> 取数脚本：`build/comparison_numbers.py` → `results/fid_onset_vs_n.csv`、`results/grid_summary.csv`；
> 拟合数字来自 `results/law_fit.json` 与 `results/law_bootstrap.json`。

## 0 对方主张（引用时的口径）

Bonnaire, Urfin, Biroli, Mézard, *Why Diffusion Models Don't Memorize: The Role of Implicit
Dynamical Regularization in Training*, **NeurIPS 2025 Oral + Best Paper**, arXiv:2505.17638。

三个可检验的主张：

| 记号 | 主张 | 含义 |
|---|---|---|
| τ_gen | 与数据量 n **无关** | 开始"生成得像"的时刻只由优化动力学决定 |
| τ_mem | 随 n **线性增长** | 开始"背下来"的时刻被数据量线性推迟 |
| n 阈值 | 超过阈值后无限训练也不背 | 安全窗口随 n 变宽，最终消失 |

他们的时间单位是**优化步（gradient steps）**，不是 epoch。这一点决定了我们所有换算。

## 1 复现：质量起点确实与 N 无关（强支持）

在**相同步数预算**（≈625 步 = 第一个检查点）下取 FID：

| N | 首个检查点 | 首个 FID | 末点 FID |
|---|---|---|---|
| 250 | e160 | 341.5 | 131.0 |
| 500 | e80 | 345.0 | 168.2 |
| 1000 | e40 | 344.3 | 210.6 |
| 1500 | e25 | 344.4 | 209.5 |
| 2000 | e20 | 337.4 | 226.2 |
| 3000 | e15 | 339.3 | 150.4 |
| 4000 | e10 | 340.3 | 137.7 |

**7 档 N 的首个 FID 极差 7.6（相对 341.7 的 2.2%）** —— 在等步数下，数据量从 250 变到 4000
完全不影响"开始生成得像"的时刻。这是对 τ_gen 与 n 无关的直接复现。

而末点 FID 随 N 单调变差（131 → 226），因为等步数预算下大 N 的"每张图被看过的次数"少
（`steps × batch / N` 从 32 降到 5）。这条也在他们的框架内：质量由步数决定，不由 epoch 决定。

## 2 出入：τ_mem 的"线性"取决于用什么口径量

同一批数据、同一个律，两种口径给出**完全不同的指数**：

| 口径 | 量 | 指数 | 怎么读 |
|---|---|---|---|
| 律的 E50（升到平台一半的轮次） | `E50 = E50₀·(N/250)^γ` | **γ = −0.848**（95% CI [−0.929, −0.739]） | epoch 坐标 |
| 同一量换到步数坐标 | `E50_steps ∝ N^(γ+1)` | **+0.152** | 比线性弱得多 |
| 固定绝对阈值 ε 的实测 onset | 首次 M ≥ ε 的步数 | ε=1%: **+0.68**；ε=2%: **+0.72**；ε=5%: **+1.52** | 7 档里只有 3–6 档有信号 |

**为什么同一件事能差这么多？** 因为我们的平台高度本身随 N 塌缩：

```
A(N) ∝ N^(−1.97)      （α = 1.969，95% CI [1.88, 2.05]）
```

在固定绝对阈值 ε 下，"什么时候越线"= `E50(N) · g(ε / A(N))`。A(N) 越小，`g` 越大
（A(N) 掉到 ε 附近时 g → ∞）。于是**幅度塌缩会被记到"时间推迟"的账上**，把 onset 的
N 斜率抬高到接近甚至超过 1。

这与文献的关系可以写成一句可检验的话：

> **τ_mem ∝ n 这个"线性"，在固定绝对阈值的口径下，会把幅度塌缩也算进时间项；
> 若按各档的平台高度归一化后再比，时间项要弱得多（我们这里 +0.15 vs +1）。**

这条不是否定他们——他们在 n 超出阈值后"永不记忆"的现象，与我们的
`A(N) ∝ N^−1.97`（平台高度塌缩）**是一致的**，只是他们用"τ 推迟到无穷"来描述，
我们用"幅度衰减到 0"来描述。两种描述在数据上可以区分，而且区分有实际后果：

- 如果是"时间推迟到无穷"：只要不训到那就没事，**数据量本身不改变最终风险**；
- 如果是"幅度衰减到 0"：数据量本身就在降低最终风险，**早停只是把风险再往前推**。

我们的 7 档数据站在后者：N ≥ 2000 在 8.5–9 万步内 M_max ≤ 4%，且**不随步数继续上涨**
（`n2000_s1` 在 e540 达 0.0059 后到 e2900 掉回 0.0039；`n4000_s1` 全程 ≤ 1.6%）。

## 3 我们这边文献里没有的两条

| 结论 | 数字 | 证据 |
|---|---|---|
| 平台高度有独立的 N 律 | `A(N) ∝ N^(−1.97 [1.88, 2.05])` | `results/law_fit.json`、`figs/fig_amplitude.png` |
| 同一 N 下不同训练子集的发作时刻抖 8–60 倍 | N=1000 的 onset 步数 2344/4688/12891/15234/18750 | `docs/NOTES.md` §8、`results/grid_summary.csv` |

第二条是文献不会报告的（他们通常单 seed 或报均值），但它直接决定工程结论：
**固定时刻表只能给期望，给不了保证**；要保证就得在线测（我们的闭环 D，28 run 零违规）。

## 4 我们的结论与他们的结论如何并用

| 问题 | 文献给的答案 | 我们给的答案 | 工程含义 |
|---|---|---|---|
| 什么时候开始背？ | τ_mem，随 n 线性推迟 | 律 L4，γ=−0.85（epoch）/ +0.15（步数） | 时间表能估，但**不能当保证** |
| 数据多了会怎样？ | 超阈值后永不背 | 平台高度 A(N) ∝ N^−1.97 衰减 | 加数据是真防线，但不免费（FID 变差） |
| 安全早停怎么定？ | 训到 τ_mem 之前 | 闭环在线测 M，停在上一个合规检查点 | 28 run 零违规，省 59% 轮次 |

## 5 引用时的写法（避免被审稿人抓）

1. **不要说"我们复现了 τ_mem ∝ n"**。我们的 E50 在步数坐标是 +0.15，不是 1。要写：
   "在等步数设定下，我们复现了生成质量起点与 N 无关；但对记忆发作时刻，我们测到的
   时间项远弱于线性，因为平台高度本身随 N 塌缩（见 §2）。"
2. 时间单位必须写清：我们的 E 是 epoch，`steps = E · N / batch`（batch = 64）。
3. 阈值口径必须写清：τ 按 FPR=0.5% 逐 N 校准（`docs/PRIVACY_AUDIT.md` §2），
   不是文献里的固定相似度阈值。
4. `A(N)` 与 `E50(N)` 的简并是这套拟合的已知弱点（`docs/NOTES.md` §10：只放开幅度
   一个自由度就能消掉 79% 的残差），引用 α 与 γ 时要同时给 CI。
