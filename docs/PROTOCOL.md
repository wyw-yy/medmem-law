# 实验协议（PROTOCOL）

> 这份文件写的是**事先定好的规则**：跑什么、跑多少、用什么判据选模型、什么情况算失败。
> 目的是让"结论"不是跑完看着图挑出来的。所有阈值都在 `config.py` 里，改了就记在这里。

## 0. 一句话

在 pathmnist 上扫 (N, E) 网格 → 每点测记忆率 M → 用三个候选律拟合 M(N,E) →
按预先声明的判据选一个 → 反解安全早停 E*(N, ε) → 用四种停训策略验证它真的更安全/更省。

## 1. 数据

| 用途 | 数据集 | 训练/验证/测试 | 备注 |
|---|---|---|---|
| 主实验 | pathmnist | 89,996 / 10,004 / 7,180 | 9 类结直肠病理，彩色 |
| 跨数据集 1 | bloodmnist | 11,959 / 1,712 / 3,421 | 8 类血细胞，彩色；**有 5 张完全重复 + 4 张近似**（已在 τ 校准中剔除） |
| 跨数据集 2 | pneumoniamnist | 4,708 / 524 / 624 | 2 类胸片，**灰度**（复制 3 通道） |
| 仅调试 | 上述 28px 版本 | — | 见 NOTES 的限制说明 |

- **嵌套子集**：`train_subset_indices` 用固定 `rng(1000+seed)` 的排列前缀，
  所以 N=250 ⊂ N=500 ⊂ … ⊂ N=4000。保证不同 N 的差异不是"换了哪批图"。
- **参照集**（校准 τ 用）：官方 test 前 2000 张，**永不参与训练**。
- 训练集/参照集之间先用 `tools/check_leak.py` 查重（md5 + 8×8 缩略图余弦）。

## 2. 主网格：等步数预算

记忆化发生在**优化步**这个尺度上，所以每档 N 给相同步数预算 `STEP_BUDGET = 20000`
（batch=64 → 每 epoch 64 步），epoch 数按 N 反比：

| N | epoch 上限 | ckpt 间隔 | 测量点数 | 说明 |
|---|---|---|---|---|
| 250 | 5125 | 160 | 32 (+ 早期间隔 25 的 43 个点) | 最长的曲线 |
| 500 | 2550 | 80 | 32 | |
| 1000 | 1275 | 40 | 32 | |
| 2000 | 650 | 20 | 32 | |
| 4000 | 325 | 10 | 32 | 最短的曲线 |

- 每个 run 约 15–30 min（28px、bf16、RTX 5070 Laptop 8 GB）。
- **主网格 = 5 N × 3 seed = 15 个 run**，队列按 seed 优先（先跑完 seed 1 的五档）。
- 每个 ckpt 采 512 张样本（DDIM 50 步、fp32）→ `cache/samples/{run}/e{E:04d}.npy`。
- ckpt 只留最近 4 个（fp16，26 MB/个）；**样本永久保留**，评分只依赖样本。

## 3. 测量

对每个 (N, seed, E)：

1. DINOv2 ViT-S/14 特征（384 维，resize 224）→ 训练集上拟合**截断白化**
   （`k = max(32, min(384, N//2))`，收缩 1e-3）。
2. 生成样本到训练 bank 的最大余弦 `sim`。
3. `M = mean(sim >= τ)`，`τ` = 参照集最大余弦的 99.5 百分位（每个 N 单独校准，FPR=0.5%）。
4. 同时记录 `sim_mean / sim_p95 / sim_max / n_leak_dropped / encoder`。
5. FID：每 4 个测量点算一次（inception_v3，real 侧统计量缓存）。
6. 另报固定阈值（0.5/0.6/0.7）下的 M，做阈值敏感性分析。

**编码器一致性是硬约束**：CSV 的 `encoder` 列一旦与当前编码器不符，`score_run` 直接拒写。
（因为实测 dinov2_s → τ=0.6721、resnet50 → τ=0.8203，混用会把 M 从 7.8% 变成 0。）

## 4. 候选律与选型判据（预先声明，防止事后挑好看的）

```
L1 拉伸指数   M = Minf·(1 - exp(-(E/E50)^β)),  E50 = c·N^γ
L2 Hill      M = Minf·E^h/(E^h + K^h),        K   = c·N^γ
L3 双时间尺度  M = Minf·Φ((E - τ(N))/w),       τ   = a·N^γ
```

拟合在 `log10(M + 1e-4)` 空间做最小二乘（小 M 区间才是安全边界），多起点避免卡在 γ 的假解。

**选型判据**（按顺序）：
1. AICc 最小；
2. 留一 N 交叉验证（用 4 个 N 拟合、预测第 5 个 N）的平均 R² 最大；
3. 参数能讲出临床含义（E50 随 N 的幂律指数 γ 是否有物理意义）。

**验收线**（写进论文的）：
- 样本内 `R²_log ≥ 0.9`；
- 留一 N 的 `R² ≥ 0.8`；
- 主图：横轴 `E/N^γ`（或 `E·N`，即"每张图被看的遍数"）时，5 条 N 曲线塌缩成一条。

合成数据自检（`build/test_law.py`）已证明这套判据能工作：
真值 γ=1.0 被复原为 0.985，L1 的 LOO R²=0.91，而 L2 只有 0.42、L3 直接负。

## 5. 安全早停

- 定义：给定可接受记忆率 ε（主报 ε=0.01，附 0.05/0.10），求最小 E 使 M(N,E) ≤ ε 对**所有 E' > E** 成立。
- 反解：在选定律上用 `brentq` 求 `M(E)=ε` 的根。
- 输出：`E*(N, ε)` 表 + `E*/N^γ` 近似常数这一条（若成立，就是"每张图看多少遍才安全"的普适常数）。

## 6. 四种停训策略（基线对比）

| 策略 | 规则 | 角色 |
|---|---|---|
| A 固定跑满 | 跑满预算 | PPT 里的"常规训练"，最不安全 |
| B FID 平台早停 | FID 连续 3 点改善 < 1% 就停 | **最该打赢的对手**：只看生成质量，不管隐私 |
| C 开环律 E*(N,ε) | 用拟合出的律直接算停点（不测 M） | 我们的方法（免测量） |
| D 闭环在线测 M | 每 25 epoch 测 M，超 ε 就回滚上一个 ckpt | 我们的方法（最安全，但要多花测量成本） |

评价指标：停训时的 epoch 数、省下的算力比例、停点处的 M、停点处的 FID、违约率
（M 超过 ε 的 run 占比）。判据：**C/D 的违约率应显著低于 A/B，且 FID 不比 B 差**。

## 7. 失败与降级

- 拟合 R² 不达标 → 先查度量（τ 是否被泄漏抬高、样本数够不够），再考虑加测量点，**不换律凑 R²**。
- 时间不够 → 按 `PLAN.md` 的降级阶梯：先砍 seed（3→1），再砍 N_max（4000→2000），再砍 E_max。
- 任何"手动改过阈值/参数"的实验，必须在 `docs/NOTES.md` 记一笔，禁止事后静默调参。
## 8. 设计修订 R1：大 N 改用「深度档」预算（2026-10-30）

**触发**：等步数主网格（每档 2e4 步）跑完后，N=2000 / N=4000 的 66 个测量点**全部 M=0**（sim_max 最高 0.63/0.64，仍低于 τ≈0.64/0.66），只有 N=250/500/1000 三档有可测的上升段。留一 N 外推检验因此崩掉（LOO R² 0.30–0.44，六种律形式都过不了预声明线 0.8）。

**判断**：瓶颈是**数据覆盖**，不是律的形式。在等步数预算下，每张图被见到的次数 N_steps/N 相同，但大 N 的记忆化起点在步数坐标上更晚（τ_mem ∝ N），所以固定的步数预算会恰好在大 N 上停在"还没开始背"的区间。

**修订**：对 N=1000/2000/4000 追加**深度档**预算，让每个 N 的 M 都进入可测区间（目标 M≈0.05–0.2），预算按「M=0.02 所需步数 ∝ N^1.3」外推：

| N | 步数预算 | epoch | ckpt_every | 依据 |
|---|---------|-------|-----------|------|
| 1000 | 3.75e4 | 2400 | 75 | 实测 M=0.02 在 ~1.0e4 步，×3.5 留足上升段 |
| 2000 | 9.0e4 | 2900 | 90 | 由 N=1000 按 N^1.3 外推 → 2.5e4 步，×3.5 |
| 4000 | 8.75e4 | 1400 | 45 | 外推 → 6.2e4 步，×1.4（显存与时间上限） |

**代价与口径**：主网格不再"等步数"，因此**数据塌缩图（M vs E/N^γ）只用等步数那 5 条曲线画**；深度档只用于**律拟合**（M(N,E) 的曲面覆盖），两者在 `metrics_long.csv` 里靠 epoch 数区分，图注必须写明。

**不改的东西**：τ 的校准口径、编码器（dinov2_s）、EMA、检出限删失处理、预声明的选型判据（AICc → 留一 N R² → 参数可解释）全部不变。这是**采样设计**的修订，不是判据的修订。

## 9. 设计修订 R2：主线分辨率改为 64×64（2026-10-30 18:30）

**触发**：R1 的深度档在 28px 上验证成功（N=2000 从 e650 的 M=0 续跑到 e2250，M 升到 **0.041–0.098**，sim_max 0.85–0.89），说明"大 N 需要更多步数"这个判断是对的，方法链路可用。但 28px 对投 Medical Image Analysis 是硬伤（分辨率影响记忆化强度），因此**主线全部改到 64×64 重跑**。

**数据来源（关键）**：官方 MedMNIST+ 的 64px npz 在 Zenodo，本机不可达（403 / DNS 失败）。改用 HF `dz-osamu/MedMNIST` 的 **224px 原始 jpg 包**，用 `build/get_hf64.py` 按 jsonl 顺序 LANCZOS 缩放到 64×64，写成与官方同键名的 npz。**切分与官方完全一致**（pathmnist：train 89996 / val 10004 / test 7180），标签分布与官方 npz 对照无异常。

**口径与代价**：
- 28px 全部结果归档到 `results/pilot28/`（CSV + 5 个 run json）与 `cache/pilot28/`（样本 + ckpt），**只作为方法验证的 pilot**，不进主结果。
- 等步数预算 `STEP_BUDGET=20000` 不变，所以每个 run 的墙钟时间几乎不变（28px 下 17–25 min，64px 下 ~35 min，多出来的主要是采样：512 张 64px 采样 17.8 s/点 vs 28px 3.5 s）。
- 但**大 N 的深度档变贵**：N=4000 的 1400 epoch 在 64px 下约 2 h（28px 下 57 min）。因此深度档改为 N∈{1000,2000} 优先，N=4000 视剩余时间决定。
- `data.ensure_dataset` 不再静默回落到 Zenodo：64px 缺文件时直接报"请先跑 build/get_hf64.py"。

**不变的东西**：τ 的 FPR 校准口径、编码器 dinov2_s、EMA、删失处理、选型判据、停训策略定义。

## 10. 设计修订 R3：候选律扩到五条（幅度衰减 L4/L5）+ 留一 N 改池化口径（2026-10-31 02:5x）

**触发**：deep 档补完大 N 预算之后，L1/L2/L3 的天花板暴露了 —— 它们都假设"平台高度 M∞ 与 N 无关"，而实测平台是 **0.80 / 0.40 / 0.07 / ≤0.01 / ≤0.02**（N=250/500/1000/2000/4000），随 N 陡降。模型在大 N 处系统性高估记忆率，留一 N（把某一档 N 整个留出）因此必然崩（折内 R² 到 −21，池化也过不了 0.8）。

**修订内容（在 cross 数据集与 seed2 出结果之前记录，避免事后挑好看的）**：
1. 新增两条候选律，与 L1/L2/L3 同台 AICc 竞争，选型判据不变：
   - `L4_amp_decay`：`M = A0·(N/250)^(-α)·[1 - exp(-(E/E50)^β)]`，`E50 = E50_0·(N/250)^γ`（5 参）
   - `L5_amp_decay_only`：同式但 `γ ≡ 0`（4 参，时间尺度与 N 无关的零假设）
   - **参数以 N0=250 为参考点锚定**：初版写成 `E50 = c·N^γ` 时 c 与 γ 强相关，优化器会跑到 c=1e5（上界）、γ=−0.67 的角落，参数不可解释。锚定后 `A0`/`E50_0` 直接读作"N=250 时的平台与半升轮次"。
2. **留一 N 的评价口径改为池化 R²**：折内 R² 在"几乎全 M=0"的留出折上没有意义（分母方差≈0，R² 会被放大成 −21 乃至 −1e6 这种量级，纯属除法假象）。池化 R² = 把所有留出折的观测点拼起来算一个 R²，另单独报 `censored_compliance`（M=0 的点是否被模型判在检出限以下）。预声明阈值仍是 0.8，**不因口径变化而放宽**。
3. 顺手修了 `fit_one`/`loo_by_n` 的多起点 bug：原来写死 `p0[3] = gamma 扫描值`，对 L4/L5 等于把 E50 钉死在 0.3–1.5；改为**按参数名**生成多起点（`_p0s`）。

**结果（pathmnist seed1，229 个点，5 档 N，deep 档已补）**：

| 律 | R²_log | R²_lin | AICc | 留一池化 | 删失合规 |
|---|---|---|---|---|---|
| L1_stretched_exp | 0.785 | 0.708 | −459.6 | 0.450 | 0.49 |
| L2_hill | 0.778 | 0.627 | −452.7 | 0.426 | 0.49 |
| L3_two_timescale | 0.744 | 0.597 | −405.7 | 0.072 | 0.32 |
| **L4_amp_decay** | **0.834** | **0.896** | **−539.7** | **0.572** | **0.77** |
| L5_amp_decay_only | 0.789 | 0.751 | −464.6 | 0.464 | 0.49 |

→ AICc 与留一池化一致选 **L4**；`α = 2.06`（平台 ∝ N^−2.06），`γ = −0.69`（epoch 坐标；换算到**优化步**坐标 `t50 ∝ N^(γ+1) = N^0.31`）。

**诚实结论（必须写进论文，不许含糊）**：
- 样本内线性 R²=0.896（≈0.9 达标），但对数 R²=0.834；**留一 N 池化 0.572 < 预声明的 0.8，外推到没测过的 N 不可靠**。
- 原因不是律形式（`build/probe_law_variants.py` 试过 6 种形式，全部卡在 LOO ≈ 0.3–0.57），而是**可测范围只覆盖 N ≤ 1000**：N≥2000 的 M 基本在检出限以下（512 样本 → 检出限 3/512 = 0.006），这些点只能当删失数据用，无法约束律的形状。
- 因此论文的主结论应表述为"在可测范围（N ≤ 1000）内控制律成立、并给出安全窗口的定量形状"，而不是"外推到任意 N"；E* 表在 N≥2000 处输出 `nan` 本身就是结论（**这些 N 在任意训练时长下都到不了 ε**）。
- 阈值稳健性（`build/probe_threshold_law.py` → `results/threshold_law.csv`）：固定阈值 0.5/0.6/0.7 下 `γ_steps = +0.20/+0.36/+0.45`、`α = 1.4/2.1/2.6`，方向一致；阈值 ≥0.8 时只有 2–3 档 N 有信号，参数不可辨识（α 撞边界），故只作参考。**结论不是靠调阈值调出来的**。

## 11. 设计修订 R4：把"开环律早停"真的接进训练循环

**动机**：`controller.py` 里的策略 C/D 是**离线回放**（拿已有测量点判断该停在哪），评审完全可以问"你们的控制器到底跑没跑过"。所以 `train.py` 增加 `--stop-law`：

- 训练开始前从 `results/law_fit.json` 读选定律，反解 `E*(N, eps)`（`law.solve_E_star`）；
- 训练到第 `ceil(E*)` 轮自动停，并在停点存 ckpt + 采样 + 写日志 `开环律早停（L4_amp_decay eps=0.01 E*=612）：E* 已到，停止训练`；
- run JSON 记 `stop_rule` / `stop_epoch_law` / `stopped_early_at`，审计链完整；
- 若该 N 永远到不了 eps（大 N 档），打印"数据本身安全"并继续按预算跑。

**验证计划**（`tools.night_queue --plan ctl`，新 seed 4，避免覆盖主网格 seed 1）：

- `pathmnist_n250_s4`：预算 5125 轮，实际应在 612 轮停（省 88%）；
- `pathmnist_n1000_s4`：预算 2400 轮，实际应在 649 轮停；
- 对照：seed 1 的满预算曲线（同 N 同分辨率），比较停点 M、FID 与后续增长。

**口径**：seed 4 vs seed 1 属跨 seed 比较，需说明；seed 2/3 的全网格跑完后可用 seed 间标准差给出不确定性。
