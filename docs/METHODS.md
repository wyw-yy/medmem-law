## 3.1 问题设定与记号

给定训练集 $D=\{x_i\}_{i=1}^{N}\sim p_{\text{data}}$（医学影像），用扩散模型在其上训练 $E$ 轮
（等价于 $S=\lceil E\cdot N/b\rceil$ 次梯度步，$b$ 为 batch）。我们关心**记忆率**

$$
M(N,E)=\Pr_{x\sim p_\theta(\cdot;N,E)}\Big[\max_{x'\in D}\ \mathrm{sim}\big(\phi(x),\phi(x')\big)\ \ge\ \tau(N)\Big],
$$

即"生成样本与训练集某张图的相似度超过阈值"的比例。三个要素各自是一个设计决定：

- $\phi$：特征编码器（§3.4）；
- $\mathrm{sim}$：白化后的余弦（§3.4）；
- $\tau(N)$：逐 $N$ 校准的阈值，锚定**假阳性率** FPR（§3.4）。

目标是拟合 $M(N,E)$ 的解析族，再反解**安全早停点**

$$
E^\*(N,\varepsilon)=\min\{E:\ M(N,E)\ge\varepsilon\},
$$

并把 $E^\*$ 变成可部署的停训准则（§3.7）。

> **为什么不是"提一个新网络"**：$M$ 是训练动力学的函数，与架构无关（同一 $M$ 定义可用于任何
> 生成器）。整篇的贡献在测量协议、控制律与控制器，不在模型结构。

## 3.2 数据

| 数据集 | 训练 / 验证 / 测试 | 类别 | 用途 |
|---|---|---|---|
| PathMNIST | 89,996 / 10,004 / 7,180 | 9 | 主实验（7 档 $N$） |
| BloodMNIST | 11,959 / 1,712 / 3,421 | 8 | 跨数据集（$N\in\{250,1000\}$） |
| PneumoniaMNIST | 4,708 / 524 / 624 | 2（灰度） | 跨数据集（同上） |

- **分辨率 64×64**（主线）。MedMNIST 官方 64px npz 在本机不可达（Zenodo 域名解析失败），
  因此从 HF `dz-osamu/MedMNIST` 的 **224px 原图**用 LANCZOS 下采样到 64（`build/get_hf64.py`），
  切分与官方逐张一致。28×28 版本是第一轮 pilot，只进附录。
- **嵌套子集**：对每个 $N$，训练子集取 `np.random.default_rng(1000+seed).permutation(N_total)[:N]`。
  同一 seed 下 $N$ 增大是**严格包含**关系，于是"多数据"与"换数据"被分开：
  $N$ 的效应不是抽样噪声，$seed$ 的效应才是。
- **参照集**：官方 test 划分的前 2000 张，**绝不参与训练**，只用于校准 $\tau$。
- 灰度集（PneumoniaMNIST）复制到 3 通道以复用同一 UNet。

## 3.3 生成模型与训练

| 项 | 值 |
|---|---|
| 骨干 | DDPM + 小型 UNet：`base_ch=32`，通道倍数 (1,2,4,8)，GroupNorm + FiLM 时间条件，**13.02 M 参数** |
| 扩散 | 线性 $\beta$：$10^{-4}\to 0.02$，$T=1000$ |
| 目标 | $\varepsilon$-prediction，MSE |
| 优化 | AdamW，lr $2\times10^{-4}$，grad-clip 1.0，batch 64 |
| 精度 | 训练 bf16 autocast，采样 fp32 |
| 采样 | DDIM，50 步，$\eta=0$，每测量点 **512 张** |
| 权重平均 | **EMA，decay 0.999**，预热 $d=\min(0.999,(1+n)/(10+n))$；**采样只用 EMA 权重** |

⚠ **EMA 不是可选的美化**：不用 EMA 时，同一个 run 的相邻检查点会采出"接近数据集均值的低对比度
块"，$M$ 在 0.88 与 0.09 之间来回跳（`figs/probe_samples.png`；诊断见 `docs/NOTES.md` §1.5）。
改用 EMA 后曲线单调。任何"记忆率随时间非单调"的结论都必须先排除这个坑。

## 3.4 记忆率测量（三个可审计的决定）

**① 特征与白化。** 编码器 DINOv2 ViT-S/14（dim 384，输入 resize 224，L2 归一后的 CLS 特征），
**离线加载**（`build/torch_home/hub`，不联网）。白化必须**截断**：$k=\max(32,\min(d,\lfloor N/2\rfloor))$，
$W=v_{[:, -k]}/\sqrt{w_{[-k:]}}$，shrinkage $10^{-3}$。
> 不截断的后果（实测）：$N=250<d=384$ 时协方差秩亏，零空间被放大 ~30 倍，所有余弦塌到 0.05，
> $\tau$ 与 $M$ 同时失效。截断后 $\tau$ 从 0.748 变 0.128（$k$=125→384）而 $M$ 只从 0.789 变 0.730
> —— **$M$ 对 $k$ 稳健，$\tau$ 不稳健**，所以只比 $M$、从不跨配置比 $\tau$（`build/probe_kdim.py`）。

**② 阈值 $\tau(N)$ 锚定假阳性率。** $\tau(N)$ = 参照集样本对训练子集的最大相似度的 $(1-\text{FPR})$
分位，**FPR = 0.5%**。含义：在"从未见过训练集"的图上，只有 0.5% 会误判成记忆。
- 校准前必须剔除泄漏：参照集里若有 $\mathrm{sim}\ge 0.99$ 的图（BloodMNIST 有 5 张完全重复 + 4 张近似），
  会把 $\tau$ 抬飞，直接导致 $M\equiv 0$。
- 敏感性：FPR 从 0.1% 放到 1%（$\tau$ 0.767→0.704），$M$ 只从 0.773 变 0.840（`build/fpr_sens.py`）。
- **编码器必须锁定**：DINOv2 的 $\tau\approx0.67$、ResNet50 的 $\tau\approx0.82$；混用会让 $M$ 归零。
  代码里已禁止静默回退（`metric.load_encoder` 抛异常而不是降级）。

**③ 去重感知。** 同时报 $M_{\text{uniq}}$（对去重后的目标集合计数），避免"少数几张图被反复复刻"
把 $M$ 抬高。实测 $M_{\text{uniq}}$ 与 $M$ 差异 < 1%（`docs/NOTES.md` §2）。

## 3.5 测量协议：等步数预算

**核心设计**：记忆化发生在**优化步**这个时间尺度上，所以每档 $N$ 给**相同步数预算**
$S_{\text{budget}}=20{,}000$ 步，$E_{\max}(N)=\lceil S_{\text{budget}}\cdot b/N\rceil$（取整到 25 的倍数）。

| $N$ | $E_{\max}$ | 检查点间隔 | 检查点数 |
|---|---|---|---|
| 128 | 10000 | 1250 | 9 |
| 192 | 6675 | 825 | 9 |
| 250 | 5125 | 160 | 33 |
| 500 | 2550 | 80 | 32 |
| 1000 | 1275 | 40 | 32 |
| 2000 | 650 | 20 | 33 |
| 4000 | 325 | 10 | 33 |

$N=128$ 与 $192$ 是补在**下界**上的两档（把"$E_{\text{onset}}/N\approx 10.5$ 常数"成立的区间从
$N\ge 250$ 往下压），只跑一个 seed、检查点更稀（9 个），因此只用于 onset 斜率，不参与主律拟合。

三个好处：①5 个 run 的墙钟时间几乎相同（35–40 min/run）；②横轴 $E/N$ 正好是理论上该塌缩的量；
③**一次训练出 32 个测量点**，不需要为每个 $(N,E)$ 单独训（15 个 run 而非上百个）。
大 $N$ 档另外追加**深度档**（$N$=1000→2400、2000→2900、4000→1400 轮）以把平台测出来。

**跨分辨率的例外**：224px 只能用 batch 16（8 GB 显存），同样 20,000–25,000 步只等于
$1{,}600$ 轮左右，而 64px 的 25,000 步是 5,125 轮。**改 batch 就改了"每张图被看几遍"**，
所以跨分辨率的比较一律按 epoch 对齐、并在表里同时报 batch（`docs/NOTES.md` §16、§16.5）。

⚠ 每个检查点都存 fp16 权重（26 MB），只滚动保留最近 4 个 + 优化器状态 1 份（否则 15 个 run 要 71 GB）。

## 3.6 控制律族与选型判据

六个候选（`law.py` 的 `CANDIDATES`；$r=N/250$）：

| 名 | 形式 | 参数 |
|---|---|---|
| L1 | $M=A[1-e^{-(E/E_{50})^{\beta}}]$，$E_{50}=c\,N^{\gamma}$ | 4 |
| L2 | Hill：$M=A/[1+(E_{50}/E)^{\beta}]$ | 4 |
| L3 | 双时间尺度（erf）：$M=A\,\Phi((E-\tau(N))/w)$，$\tau=aN^{\gamma}$ | 4 |
| **L4** | **$M=A_0r^{-\alpha}[1-e^{-(E/(E_{50,0}r^{\gamma}))^{\beta}}]$** | **5** |
| L5 | L4 但 $\gamma\equiv0$ | 4 |
| L6 | L4 但幅度指数衰减 $A_0e^{-(N-250)/N_c}$ | 5 |

**拟合**：在 $\log_{10}M$ 空间做非线性最小二乘（`scipy.optimize.least_squares`），
**多起点**按参数名生成（$\gamma\in\{0,.5,1,1.5\}$ × 尺度参数 $\in\{0.5,1,3\}$）。

⚠ **删失处理**：$M=0$ 不是"$M$ 恰好等于 0"，而是"低于检出限"。每个点的检出限取
$3/n_{\text{gen}}$（0 命中时的 95% 二项上界）。残差：
- $M>0$：$\log_{10}\hat M-\log_{10}M$；
- $M=0$：单侧 softplus 罚 $\frac{1}{K}\log(1+e^{K(\log_{10}\hat M-\log_{10}m_{\text{det}})})$，$K=4$。

**判据（预声明，见 PROTOCOL §10/§14）**：AICc 最小 → 留一 $N$ 的**池化** $R^2$ 最大 → 参数可解释。
⚠ 折内 $R^2$ 在"几乎全 0"的留出折上无意义（分母方差≈0，实测出现过 $-10^6$），所以用池化口径。

**口径**：主拟合用 **seed 均值曲线**（$M$ 是期望记忆率，seed 差是噪声）；另报逐 run 口径作敏感性。
两条都不为抬 $R^2$ 而换。

## 3.7 四种停训策略与在线闭环

| 策略 | 规则 | 需要什么 | 交付点语义 |
|---|---|---|---|
| A | 跑满预算 | 无 | 末点 |
| B | FID 平台早停（相邻两点改善 < 2%） | 需参照集算 FID | 平台点 |
| C | 开环律：$E^\*=E^\*(N,\varepsilon)$ | 预先拟合的律 | $\lceil E^\*\rceil$ |
| **D** | **闭环：每个检查点现测 $M$，越界即停** | 只需参照集（不需先验律） | **最后一个仍合规的检查点** |

⚠ **交付点语义是评测 bug 的高发区**：发现越界后不能把"越界的那个检查点"当交付物，必须回退到
上一个合规点（部署时丢弃越界权重）。修正前 D 的违规率被报成 87%，修正后 0%。

**在线闭环的实现**（`train.py --stop-eps`）：训练开始前用参照集校准 $\tau$（约 10 s，只做一次）；
每个检查点采样 512 张 → 编码 → 算 $M$；若 $M\ge\varepsilon$，记 `M_at_detect` 并停，
把 `deliver_epoch` 记成上一个合规点。成本：每点约 17 s（64px、8 GB 卡），相对 20–40 min 的训练可忽略。

## 3.8 安全交付判据（严格口径，四个条件同时成立）

对每个 $(dataset,N,\varepsilon)$：

1. **最差 seed 合规**：$\max_{\text{seed}}M(E^\*_{\text{deliver}})\le\varepsilon$（不是均值合规）；
2. **经验停点不违约**：$E^\*$ 不晚于任何 seed 的首次越界点（$E^\*_{\le}=E^\*_{\text{emp}}$）；
3. **质量代价可接受**：$\mathrm{FID}_{\text{stop}}\le1.5\times\mathrm{FID}_{\text{full}}$；
4. **$\varepsilon$ 高于假阳性地板**：$\varepsilon>2\times\text{FPR}=1\%$（否则"0.5% 的误报"本身就是答案的一部分）。

> 这条口径是**故意严的**：放宽到 $\mathrm{FID}\le2\times$ 或允许均值合规，能多出 3–4 行"可交付"，
> 但那是把审稿人该挑的刺留给审稿人。最终结果是 **27 行里 0 行全过**，并且这本身就是结论：
> 小数据上隐私合规与生成质量不可兼得。

## 3.9 统计推断与独立复算

- **Bootstrap**：按 $N$ 分层重采样 200 次，输出参数与 $E^\*$ 的 95% CI
  （$\gamma=-0.848$，CI $[-0.929,-0.739]$，不含 0 —— 这是"时间尺度随 $N$ 变"的统计依据）。
- ⚠ **区间与点估计必须喂同一张表**：第一版 `law_ci.py` 用"全数据集 + 逐 seed"的表做区间，
  而主律是"pathmnist + seed 均值" → 区间描述的是另一个量。这个问题是 R 复算抓出来的。
- **R 独立复算**（`R/verify_in_R.R`，**base R 零外部包**）：同一模型、同一删失罚、同一多起点，
  用 `optim(L-BFGS-B)` 重拟合；逐点预测差 0、四个 $R^2$ 逐位相同、参数一致到 $10^{-6}$。

## 3.10 可复现性与审计链

- `results/metrics_long.csv` 是**唯一真相来源**（每行一次测量，含 `encoder` 列）；
  所有图表都从它派生，不手写数字。
- `tools/audit.py`：检查重复行、run 内编码器/$\tau$ 唯一、越界值、点数下限（干预组豁免）、
  CSV 末轮 vs run JSON 的 `epochs_done`。
- `build/verify_claims.py`：把验收标准逐条变成可执行断言，从原始产物重算（当前 17 PASS / 3 FAIL）。
- 每次实验的预算、停点、交付点都写进 `results/runs/{run}.json`，与 CSV 交叉核对。
- 脚本与文档全部进 git（`build/*.py`、`R/`、`docs/`）；`results/*.csv` 与 `runs/*.json` 进 git，
  大文件（npz、ckpt、samples）不进。

## 3.11 计算预算（实测）

| 项 | 数值 |
|---|---|
| 单 run（20k 步，64px） | 35–40 min（0.4–7.0 s/epoch 随 $N$ 线性变化） |
| 每测量点采样 512 张 | 17.8 s（64px，DDIM 50） |
| 全部实验 | 40 个 run、1282 个测量点、约 40 GPU·h（含深度档、闭环、224px 与下界探针） |
| 评测（编码 + FID） | 每点约 30 s；`--fid-stride 4` 时约 15 s |
| 显存峰值 | 2.19 GB（训练）/ 2.6 GB（采样+编码） |

> 也就是说：整套结果在**一张 8 GB 笔记本卡**上一天多能重跑完。这是刻意的设计目标——
> 让审稿人/医院能自己复现，而不是依赖大算力。
