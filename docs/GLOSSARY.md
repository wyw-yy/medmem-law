# 术语表（新人先读这个）

> 每个词都对应代码里的一个具体东西。看不懂论文时先回这里查。

## 课题核心量

**记忆率 M（memorization rate）**
一个 checkpoint 生成 `n_gen` 张假图，每张去训练集里找"最像的一张"，算出余弦相似度；相似度超过阈值 τ 的假图就算"被记住了"。
`M = 超过 τ 的假图数 / 总假图数`。代码：`metric.memorization_rate`，结果在 `metrics_long.csv` 的 `M` 列。

**τ（阈值）**
不是拍脑袋定的。取一个**从未参与训练的非成员集**（同数据集的 test split），让每张非成员图也去训练集里找最像的一张，得到一堆相似度；τ = 这堆相似度的 **99.5 百分位**。
含义：真·非成员图只有 0.5% 会超过 τ（这就是 `FID_FPR=0.005`），所以"超过 τ" 基本就是"不是你训练集里的东西却像到离谱"。
代码：`metric.calibrate_tau`。

**近邻距离 / 相似度**
用 DINOv2-S 把图变成 384 维向量（`metric.encode`），再做**白化 + 降维到 k 维**（`metric.fit_whitening`），最后算归一化向量的内积（就是余弦）。白化是为了压掉"所有自然图都像"的那几个主方向，不白化的话任何两张图都 0.9+，根本分不开。

**M_uniq（去重感知记忆率）**
同一张训练图被记住了好几次时，M 会虚高。`M_uniq` 只算"有多少张不同的训练图被复刻"，是更保守的隐私指标。

## 控制律里的参数

**E**：训练轮次（epoch）。**N**：训练集规模（张）。
**M∞**：E→∞ 时记忆率的天花板。
**E50**：记忆率达到 `M∞/2` 所需的 epoch 数 —— 曲线的"膝盖"。
**β**：曲线在膝盖附近的陡峭程度（β>1 是 S 形）。
**γ**：`E50 = c·N^γ` 里的指数。**这是本文最核心的一个数**：γ≈1 说明"数据翻倍，开始背的 epoch 也翻倍"；γ>1 说明大数据更安全；γ=0 说明加数据没用。
代码：`law.model_L1` / `model_L2` / `model_L3`。

**数据塌缩（data collapse）**
如果律对，把横轴换成 `E / N^γ`，5 条不同 N 的曲线会叠成一条。物理里叫标度塌缩，是"这个律是真的"的强证据。图：`figs/fig_collapse.png`。

**留一 N（leave-one-N-out, LOO）**
用 4 档 N 拟合、预测剩下的那一档。比样本内 R² 诚实得多：L2（Hill）样本内 R² 能到 0.998，留一只有 0.42 —— 因为它把 N 的效应拟合成了曲线噪声。
所以验收线写的是"样本内 R²_log≥0.9 **且** 留一 R²≥0.8"。

**AICc**
带小样本修正的赤池信息量：`AICc = n·ln(SSE/n) + 2k + 2k(k+1)/(n-k-1)`。在**样本内**奖励拟合好、惩罚参数多，用来在同族模型里选。三候选律里 L1 参数 4 个、L2 5 个、L3 4 个。

## 实验设计

**等步数预算（equal-step budget）**
记忆化发生在**优化步**这个时间尺度上，所以每档 N 给同样的步数（`STEP_BUDGET=20000`），epoch 数按 N 反比缩放（`config.epochs_for`）。
N=250 → 5125 epoch（每 160 存一个点）；N=4000 → 325 epoch（每 10 存一个点）。5 个 run 耗时几乎一样。

**measurement point（测量点）**
一个 checkpoint 对应的一次测量：采样 `N_SAMPLE=512` 张 → 算 M / sim_mean / sim_p95 / sim_max / FID。每个 run 32 个点。

**EMA（指数滑动平均）**
采样必须用 EMA 权重。用原始权重时，有些 checkpoint 会采出"接近数据集均值"的低对比度图，M 会从 0.88 掉到 0.09，曲线出假锯齿。详见 `docs/NOTES.md` §1.5。

**FPR（假阳性率）**
τ 校准时的目标：非成员图被误判为"被记住"的比例。我们固定 0.5%。

## 停训策略（论文第 4 节）

| 名字 | 做法 |
|---|---|
| A_fixed_max | 跑满预算（PPT 里的基线，"没有早停控制的常规训练"） |
| B_fid_plateau | FID 连续几个点不再改善就停（**最该打平的对手**） |
| C_open_loop | 用拟合好的律直接算出 E\*(N,ε)，训练前就定好停在第几轮 |
| D_closed_loop | 每个测量点实测 M，M ≥ ε 立刻停 |
| Dp_closed_predict | 实测 M + 斜率外推，预测"下一个点会越界"就提前停 |

评价：停在第几轮（成本）、停时 M（隐私）、停时 FID（质量）、是否 M_stop ≤ ε（合规）。
