## 已知偏差（必须写进论文 limitation，不许藏）

1. **可测范围只到 N ≤ 1000**。N≥2000 的档在 3.75–9 万步内 M 基本低于检出限（3/512 = 0.006），只能当删失数据；留一 N 外推到这些档必然不可靠（留一池化 0.473 < 预声明 0.8；逐 run 口径 0.666）。**主结论限定在 N ≤ 1000 的可测区间**，大 N 处只给"上界：没测到记忆化"。
2. **数据是 MedMNIST 打包版，不是原始 DICOM**。没有 PACS、设备、扫描协议层面的异质性；院内数据接入只能给流程建议（用户已确认院内数据推迟数周 → future work）。
3. **阈值口径比 PPT 更严**。用"非成员相似度的 99.5 百分位"（FPR=0.5%）逐 N 校准；已用固定阈值 0.5–0.95 做稳健性扫描（`results/threshold_law.csv`），阈值 0.5–0.7 下结论同向，≥0.8 时参数不可辨识。
4. **时间单位换算**。文献用优化步，本项目主坐标用 epoch；`1 epoch = N/64 步`。本报告同时给两种坐标：epoch 坐标 γ=−0.69 ⟺ 步数坐标 t50 ∝ N^0.31；而**到 ε 的实测步数斜率是 0.79–1.29**（后者与文献更接近，也更好解释）。
5. **模型容量小（13M）、分辨率 64×64**。结论在更大模型 / 224px 原始分辨率上的可迁移性未验证（224px 数据已在本地缓存，可作下一步）。
6. **early stop 的代价是图像质量**。N=250 在 ε=0.01 处早停省 91% 轮次，但 FID 从 123 升到 341 —— 论文必须把"隐私—质量"权衡画成一条曲线，而不是只报"省了多少轮"。
