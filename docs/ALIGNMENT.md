## 已知偏差（必须写进论文 limitation，不许藏）

1. **律的预测力有天花板，且我们测出了天花板在哪**。样本内 R²_lin 0.710、R²_log 0.682、留一池化 0.464，都低于预声明的 0.9 / 0.8（补齐 N=1500/3000 深度档、并把 seed 补到 7–9 个之后比 3-seed 版本更低，见 `docs/NOTES.md` §11、§13）。
   原因不是模型形式（六种律形式、纯可测点重拟合、换阈值重拟合，全部落在 0.70–0.83），而是**同一 N 下不同 seed（训练子集）的发作步数相差最多 8 倍**（N=1000 实测：2344 / 4688 / 12891 / 15234 / 18750 步）。这个子集方差比 N 从 250 涨到 1500 的系统位移还大。
   所以：**律描述的是期望记忆率，不能当单个 run 的保证**。这条正是把交付物从"固定时刻表"改成"闭环监测"的实证依据。
2. **可测范围只到 N ≈ 1000–1500**。N≥1500 的档即使给到 8 万步（4× 等步数预算），M_max 仍只有 1–3%（N=1500 平台 0.021、N=2000 0.007、N=3000 0.011、N=4000 0.014，其中 2000/3000/4000 已贴到 3/512 的检出限），只能当删失数据；留一 N 外推到这些档必然不可靠。**且这些 M 是上界不是复刻率**：用原文 Eq.(6) 的像素最近/次近比复算 `pathmnist_n2000_s2`，`f_mem` 在 e450/e540/e2900 都是 **0.000**（像素比中位 0.97–0.98），说明那 21 张越线样本只是"像"而不是复刻（`docs/COMPARISON.md` §2.2、`docs/NOTES.md` §15.4）。
3. **数据是 MedMNIST 打包版，不是原始 DICOM**。没有 PACS、设备、扫描协议层面的异质性；院内数据接入只能给流程建议（用户已确认院内数据推迟数周 → future work）。
4. **阈值口径比 PPT 更严**。用"非成员相似度的 99.5 百分位"（FPR=0.5%）逐 N 校准；固定阈值 0.5–0.95 稳健性扫描：0.5–0.7 结论同向，≥0.8 时参数不可辨识；FPR 放大 10 倍 M 只动 4 个百分点。
5. **时间单位换算 + 一个模型层面的混淆**。文献用优化步，本项目主坐标用 epoch（`1 epoch = N/64 步`）：γ_epoch=-0.831 ⟺ 名义 t50 ∝ N^0.169；而**实测 onset（首越 1%）在可测区间的斜率是 0.95 ≈ 线性**。补测的 N=128/192 两档只能给 onset 上界（首个检查点即越线），且白化维数与主网格不同尺，故只作方向旁证、不进拟合（`docs/NOTES.md` §17）。两者不一致是因为 L4 里"幅度随 N 衰减"与"时间尺度随 N 平移"部分可互换（简并），固定绝对阈值会把幅度塌缩折算成时间推迟，所以**报告里以实测 onset 斜率为主，γ 只作为模型参数**（`docs/COMPARISON.md` §2.4）。
6. **早停的代价是图像质量：没有哪个配置能同时满足隐私与质量**。安全表 28 行里，"四条件全过"为 0 行；小 N 档早停后 FID 涨 2–3 倍（如 N=250：123 → 341）。论文必须把"隐私—质量"权衡画成曲线，并明确：**想在给定隐私预算下同时保住质量，唯一的办法是加数据，而不是调早停点**。
7. **模型容量小（13M）、分辨率 64×64**。结论在更大模型上的可迁移性未验证。
   224px 已经真跑过两档。**pneumoniamnist N=1000（30,000 步、8 × 128 张）判 inconclusive**（`M` 全程 0、
   `sim_max` 0.24–0.27 低于 τ=0.352，但 FID 110–121、保真度不足以把"不记忆"与"还没学会复刻"分开）。
   **bloodmnist N=250 这一档给出了可判读的结论，但口径必须改**：224px 只能跑 batch 16，
   25,000 步只有 1,600 轮，而 64px 主网格 20,000 步是 5,125 轮 —— **等步数 ≠ 等重复次数**（差 3.2 倍）。
   按 epoch 对齐后，64px 在 `E=1600` 已 `M=0.375`（`sim_max` 0.787），224px 到 `E=1600` 仍 `M=0`
   （`sim_max` 0.315–0.365，FID 仍从 371 稳降到 209）→ **分辨率把 onset 至少推后到 1,600 轮之外**；
   224px 自身的平台未测到（已续训到 `E=6,400` 再评分，见 `docs/PROTOCOL.md` §24.5、`docs/NOTES.md` §16）。
   因此论文里**不写"分辨率不改变结论"**，只写"64px 的定量系数不跨分辨率推广，224px 的 onset 更晚"。
