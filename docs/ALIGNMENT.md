## 已知偏差（必须写进论文 limitation，不许藏）

1. **分辨率 28×28**。立项时计划 MedMNIST 64×64，但官方 64px 源（Zenodo）在本机网络下不可达（403 / DNS 失败），改从 HF 镜像取 28px 版。影响：说服力弱于 64px；补救方案是 W5 用 64px 复跑 N=250/1000 两档做分辨率敏感性（HF 上有 64px 版本可下载）。
2. **数据是 MedMNIST 打包版，不是原始 DICOM**。没有 PACS、设备、扫描协议层面的异质性；院内数据接入路径只能写"流程建议"，不能给实测。
3. **阈值口径比 PPT 更严**。PPT 只说"超过阈值"，本项目用"非成员相似度的 99.5 百分位"（FPR=0.5%）逐 N 校准 —— 更可辩护，但需要在结果里同时给出固定阈值 0.5/0.6/0.7 下的 M 做稳健性检验，避免"结论依赖阈值"的质疑。
4. **时间单位换算**。NeurIPS 2025 Oral 原文用"优化步"，本项目主坐标用 epoch；换算关系 `1 epoch = N/BATCH 步`，γ 因此在两种坐标下差一个指数因子，论文必须写明用的是哪个。
5. **模型容量小（13M）**。PPT 没规定模型规模，但要说明结论在更大模型上的可迁移性未验证。
