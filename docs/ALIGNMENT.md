## 已知偏差（必须写进论文 limitation，不许藏）

1. **律的预测力有天花板，且我们测出了天花板在哪**。样本内 R²_lin 0.774、R²_log 0.709、留一池化 0.442，都低于预声明的 0.9 / 0.8。
   原因不是模型形式（六种律形式、纯可测点重拟合、换阈值重拟合，全部落在 0.70–0.83），而是**同一 N 下不同 seed（训练子集）的发作步数相差最多 8 倍**（N=1000 实测：2344 / 4688 / 12891 / 15234 / 18750 步）。这个子集方差比 N 从 250 涨到 1500 的系统位移还大。
   所以：**律描述的是期望记忆率，不能当单个 run 的保证**。这条正是把交付物从"固定时刻表"改成"闭环监测"的实证依据。
2. **可测范围只到 N ≈ 1000–1500**。N≥1500 的档在 3.75–9 万步内 M_max 多数 <5%（即不到 25 张图），只能当删失数据；留一 N 外推到这些档必然不可靠。
3. **数据是 MedMNIST 打包版，不是原始 DICOM**。没有 PACS、设备、扫描协议层面的异质性；院内数据接入只能给流程建议（用户已确认院内数据推迟数周 → future work）。
4. **阈值口径比 PPT 更严**。用"非成员相似度的 99.5 百分位"（FPR=0.5%）逐 N 校准；固定阈值 0.5–0.95 稳健性扫描：0.5–0.7 结论同向，≥0.8 时参数不可辨识；FPR 放大 10 倍 M 只动 4 个百分点。
5. **时间单位换算 + 一个模型层面的混淆**。文献用优化步，本项目主坐标用 epoch（`1 epoch = N/64 步`）：γ_epoch=−0.848 ⟺ t50 ∝ N^0.152；但**实测 onset 斜率是 0.64**。两者不一致是因为 L4 里"幅度随 N 衰减"与"时间尺度随 N 平移"部分可互换（简并），所以**报告里以实测 onset 斜率为主，γ 只作为模型参数**。
6. **早停的代价是图像质量：没有哪个配置能同时满足隐私与质量**。安全表 27 行里，"四条件全过"为 0 行；小 N 档早停后 FID 涨 2–3 倍（如 N=250：123 → 341）。论文必须把"隐私—质量"权衡画成曲线，并明确：**想在给定隐私预算下同时保住质量，唯一的办法是加数据，而不是调早停点**。
7. **模型容量小（13M）、分辨率 64×64**。结论在更大模型 / 224px 原始分辨率上的可迁移性未验证（224px 源已在本地缓存，可作下一步）。
